# POWER IMPORTER v0.7.0 — Pre-release

A unified Blender browser for existing local and network asset libraries, inspired by the availability of Sand3D collections and expanded to support long-established user libraries.

## Highlights

- Keep the sidebar, open a dedicated Power Importer workspace, or browse in an independent Blender window.
- Import into an explicitly remembered window, scene and View Layer; destination changes or closure block the operation before mutation.
- Search by words or wildcards, filter formats, use detailed lists or thumbnail views and page through large results.
- Import USD, OBJ/MTL, STL, GLB/glTF and supported standalone BLEND files; use images for materials, textures and planes.
- Prepare thumbnails and Blender assets in an isolated background process.
- Restore missing textures manually or continue without them; configure separate general/error logs.
- Back up and restore settings with the add-on or the separate Windows utility, including local, mapped-drive and UNC library paths.

## Downloads

- `sand3d_browser-0.7.0.zip`: installable Blender add-on; do not install the automatically generated repository source archive as an add-on.
- `MZERMARTS-PowerImporter-Reglages.exe`: Windows settings utility; requires an installed Blender, run in background mode. Close interactive Blender sessions first.
- `mzermarts_power_importer_settings.py`: standalone settings helper for Blender.
- `SHA256SUMS-v0.7.0.txt`: checksums of the three downloads above.

## Compatibility and validation

Tested with Blender 5.0.0 on Windows using isolated profiles and generated fixtures. Tests cover cross-scene destination routing, image application to the source mesh, refusal after destination changes/closure, workspace reuse, formats, settings restoration, pagination and texture recovery. Blender 4.2/5.2 compatibility remains to be validated.

## Known limits

This is a pre-release. Complex rigs/shaders are not comprehensively certified. BLEND files compressed with Zstandard, files from newer Blender versions and linked BLEND libraries are rejected. Model thumbnails require preparation; drag-and-drop uses Blender’s native Asset Browser afterwards. 3MF/FBX/DAE are inventory-only. Multiselection, batch conversions and export presets are planned toward 1.0, not included here. Source files remain unchanged; backups contain settings, not assets. Review literal paths when sharing a configuration between machines.

## Upgrade

Export current settings, save your work, install the add-on ZIP and restore the JSON if needed. The module remains `sand3d_browser`. Reindex after upgrade and bind the intended destination from its Layout before using the independent browser.
